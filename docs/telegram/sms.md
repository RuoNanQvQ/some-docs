# 接码注册换绑使用说明

通过我们提供的服务，你可以借此完成 Telegram 的注册和换绑操作，但是一般不推荐注册，因为风控严重而且很多人没技术也不会注册只会瞎搞！

!> 首先明确一点：无论注册或换绑，必须使用官方正版移动客户端，下面是地址，其它任何版本的客户端均不会收到验证码。

苹果：https://apps.apple.com/us/app/telegram-messenger/id686449807  
安卓：https://play.google.com/store/apps/details?id=org.telegram.messenger

## 账号换绑

这个没什么好说的，进入个人资料页面找到手机号，按照提示输入新手机号，获取验证码完成换绑即可；如果提示号码已经被使用，等待三分钟后刷新页面会得到新手机号，再发验证码即可。
