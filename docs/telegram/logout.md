# Telegram 系统设备被强制下线说明

在使用过程中，您可能会看到如下提示图片：

<div style="display: flex; gap: 10px;">
  <img src="docs/telegram/images/3.png" alt="sms" style="width: 50%; height: auto;">
</div>

> 系统之所以能收到验证码，是因为我们的云端设备已经登录并保持在线。部分用户在登录自己的设备后，会将我们的系统设备强制下线（踢出登录状态），
> 这样一来，我们的接码功能就会失效，后续也无法再获取验证码。

!> 遇到这种情况，目前没有任何解决办法。如果您需要长期获取验证码，请务必保持我们的云端设备始终在线，不要将其踢下线。
