# Telegram 成品号登录短信/邮箱验证说明

如果你在使用官方移动端客户端登录时，可能会遇到需要短信或邮箱验证的提示，界面如下：

<div style="display: flex; gap: 10px;">
  <img src="docs/telegram/images/2.png" alt="sms" style="width: 50%; height: auto;">
  <img src="docs/telegram/images/1.png" alt="email" style="width: 50%; height: auto;">
</div>

**这两种验证其实是官方移动端的“诱导”行为，账号本身没有任何问题。你可以通过更换其他客户端登录，直接跳过验证。**

!> **‼️‼️‼️【这个方法同样适用于手机端经常收不到验证码的情况】**

---

目前已知电脑客户端和网页版都可以直接跳过验证。

- 网页版：[https://web.telegram.org/a](https://web.telegram.org/a)
- 苹果手机：将 App Store 切换到美区，搜索并安装 **Swiftgram** 或 **Nicegram**，登录即可。
- 安卓手机：直接下载并安装 **Nekogram**，[点此下载](https://github.com/Nekogram/Nekogram/releases/download/v12.1.1/Nekogram-12.1.1-6211-universal.apk) 后登录即可。
