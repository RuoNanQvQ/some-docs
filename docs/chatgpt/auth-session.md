# Auth Session 提取

**Auth Session 是什么？**

一个文件，简单理解为就是 ChatGPT 的登录令牌，通过此令牌开通会员过程中就可以避免异地登录，造成账号状态异常等情况出现；同时也可简化开通流程。

## 提取方法

- 1.电脑打开地址 https://chatgpt.com/ 按照正常流程登录账号，保证账号在线。
- 2.相同浏览器，打开地址 https://chatgpt.com/api/auth/session 能看到长文本，网页右键另存为保存到文件。

## 后续使用

将刚才保存的文件直接发给对方即可，对方会给教你下一步提示，按照提示继续操作就行。
