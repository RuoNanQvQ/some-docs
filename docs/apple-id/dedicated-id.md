# 苹果独享ID

发货里面的内容会以下东西 账号 密码 生日 密保内容(三个问题答案)

## 新环境登录账号提示锁定或异常怎么办？

最近苹果有了新的风控策略：部分客户拿到独享号后，在新环境里**登录账号**，有较大概率触发风控锁定。

**解决办法：**

1. [点此解除账号锁定](https://iforgot.apple.com/password/verify/appleid)（选择密保验证）
2. [点此登录账号](https://account.apple.com/)并开启双重验证

!> **售后规则：质保首登。** 完成登录、账号正常的那一刻即视为交易完成。之后因共享、修改资料等行为导致的问题，不在售后范围。
